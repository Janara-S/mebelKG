# MebelPro KG — кликабельный прототип

Облачная система для мебельных цехов Кыргызстана: 3D-проект → детали → раскрой → документы и смета в сомах.
Статический прототип без сервера: HTML + Tailwind (CDN) + Three.js r128.

## Экраны

| Файл | Экран |
|---|---|
| `index.html` | Главная страница (3D-демо кухни, тарифы, FAQ) |
| `auth.html` | Вход и регистрация (демо, данные никуда не отправляются) |
| `pricing.html` | Тарифы и демо-оформление подписки |
| `dashboard.html` | Панель цеха: KPI, канбан этапов, реестр заказов, склад, роли |
| `projects.html` | Мои проекты + окно «Новый проект» |
| `studio.html` | 3D-конструктор: выбор модуля, размеры, взорванный вид, день/ночь, проверки |
| `cutting.html` | Раскрой, спецификация, этикетки, КП, сравнение версий; `#docs` — документы |
| `soon.html?s=…` | Заглушка для разделов, которых ещё нет |

## Как всё связано

`assets/data.js` — единственный источник данных. Расчёт идёт по цепочке:
модули кухни → детали (с вычетом толщины ЛДСП и зазоров фасадов 2 мм) →
гильотинный раскрой листов 2800×2070 (пропил 4,2 мм, обпил 15 мм) → кромка и фурнитура →
себестоимость и маржа → проверки (пересечения, коммуникации, проход до острова и т. д.).

Правки размеров в 3D-конструкторе сохраняются в `localStorage` браузера, поэтому раскрой,
смета, этикетки и сравнение с подписанной версией v1.2 сразу показывают новые цифры.

- Каталог: 29 модулей (нижние, верхние, пеналы и шкафы, остров). Нажмите «+» или перетащите карточку в 3D — модуль встанет на свободное место. Режим «Двигать» — тянуть шкаф мышью вдоль стены с привязкой к соседям. Удаление — Delete, копия, «прижать к соседу».
- Шаблоны: прямая кухня по длине стены (мойка у воды, ПММ, духовка, пенал, верхние), с островом, распашной шкаф, прихожая, пустая комната. При создании проекта шаблон подбирается по типу мебели и размерам комнаты.
- Фальш-планки: щели 4–149 мм до стены и между модулями закрываются автоматически и попадают в раскрой.
- Наполнение: полки, внутренние ящики, штанга для одежды, сушка для посуды — в 3D, деталях и фурнитуре.
- Монтажные чертежи: развёртка стены А с цепочками размеров и высот, план сверху с проходом — `cutting.html#drawings`, печать в PDF.
- Цвета: в 3D-конструкторе (панель «Цвета проекта») выбираются фасады, корпус и столешница, а для отдельного модуля — свой цвет фасадов. Фасады разных цветов раскраиваются на отдельных листах, цена декора входит в себестоимость. Цвета можно выбрать и при создании проекта.
- `assets/scene3d.js` — 3D-сцена: шкафы собраны из настоящих панелей, поэтому взорванный вид раскладывает корпус на детали.
- `assets/layout.js` — шапка, боковое меню, навигация, уведомления, переключатель RU/KG.

## Один файл: `mebelpro.html`

Все экраны, стили и скрипты собраны в один файл `mebelpro.html`. Его можно переслать
или открыть без остальных файлов. Экраны переключаются через адрес: `mebelpro.html#/studio`,
`#/cutting/docs`, `#/pricing?plan=pro` и т. д.

Файл генерируется из многофайловой версии — правьте исходники, затем пересоберите:

```bash
perl tools/build-single.pl
```

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер в корне папки, например:

```bash
npx serve .
```

Нужен интернет: Tailwind, Three.js и шрифты загружаются с CDN.

## Что пока демо

- Оплата MBank / О!Деньги / Элкарт: имитация, деньги не списываются и данные карт не запрашиваются.
- Вход и регистрация: без сервера, только переход в кабинет.
- Кыргызский язык: переведено только меню.
- Экспорт для ЧПУ: DXF (контуры листов и деталей) и CSV. Постпроцессоры `.mpr`/`.cix`/G-code не реализованы.
- Полные 3D и раскрой построены для заказа №2025-104; остальные заказы — карточки в реестре.
